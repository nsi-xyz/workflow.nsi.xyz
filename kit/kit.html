Piloter l'agent — au quotidien

La méthode, les règles, et quoi faire quand ça bloque
Identifiant : {{ALIAS}}

La méthode, en 5 temps (à chaque demande)

1. Décrire — dis ce que tu veux, avec le critère de réussite.   2. Générer — l'agent écrit le code.   3. Tester — tu lances et tu regardes pour de vrai.   4. Corriger — décris l'écart précisément.   5. Livrer — on enregistre et on publie.

Une demande = un objectif. Si tu mélanges deux choses, découpe.

Ce que fait l'agent tout seul : la trace

À chaque échange, l'agent doit :

  • écrire un fichier dans journal/ (ton message exact + un résumé + les fichiers modifiés) ;
  • faire un commit et push sur GitHub.

C'est cette trace qui est regardée pour évaluer ton travail — pas seulement le résultat final. S'il oublie, dis-lui : « consigne cet échange dans le journal, puis commit et push ».

Les règles d'or

Secrets
Aucune clé ni mot de passe dans un fichier du projet. La clé vit dans .env, ignoré par Git.
Données personnelles
Aucun nom, téléphone, adresse, photo dans le dépôt, le site ou un message à l'agent.
Ressources légères
Images et sons optimisés : aucun fichier de plus de 10 Mo.
Droits
Aucun contenu sous copyright : respecte les droits d'auteur et les marques (images, sons, polices, noms).
Tu n'as pas à lire le code. Ce qui compte, c'est l'organisation du projet : à quoi sert chaque fichier. Un problème ? Décris-le et colle le message d'erreur entier à l'agent : il saura le corriger. S'il s'embrouille, compacte (/compact) ou relance une session propre dans le même dossier — tes fichiers ne bougent pas.

En cas de problème : demande à l'agent

Tu n'as personne à contacter. Ouvre ton agent et recopie le problème en entier (message d'erreur compris). Exemples :

  • « Configure le dépôt Git à ma place (identité, .gitignore, projet.json), en m'expliquant. »
  • « git push ne fonctionne pas. Voici le message exact : … »
  • « Le jeu ne s'affiche pas. Voici l'erreur complète : … »
  • « Explique-moi ce que tu viens de faire, fichier par fichier, comme à un débutant. »
Réflexe : coller le message d'erreur entier fait gagner des dizaines de minutes. « Ça marche pas » ne permet pas de t'aider.
